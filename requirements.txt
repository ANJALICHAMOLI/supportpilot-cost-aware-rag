# (langchain-core, langchain-groq, langchain-google-genai, langchain-chroma,
# langchain-community, langchain-text-splitters, langchain-huggingface) rather
# than one giant "langchain" install? Since ~2024 LangChain split its monolithic
# package into smaller ones per integration. Installing only what we use keeps

# interviewer) skimming this file to understand the tech stack at a glance.
